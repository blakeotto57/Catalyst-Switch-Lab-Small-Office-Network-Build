# Catalyst-Switch-Lab-Small-Office-Network-Build
I bought 3 Cisco Catalyst switches to gain experience with hands-on networking experience. I know the CLI from Cisco Packet tracer and have done numerous simulate labs via that program but I wanted to gain as much real-world experince and practice as I can to get a better feel of real-world applications of these networking concepts.
The Hardware I used:
- 1 Cisco Catalyst 2560 Series (Layer 2 Switch), Version:
- 1 Cisco Catalyst 3500 Series XL (Layer 2 Switch), Version:
- 1 Cisco Catalyst 3560G Series (Layer 3 Switch), Version: 
- Numerous ethernet cables
- Claude/Google to troubleshoot commands

I asked Claude to generate me a list of requirements for this Small Office Network Build and the attached link is what it generated for me to do. It covers Networking concepts like: VLANs, 802.1Q trunking, LACP EtherChannel, Rapid PVST+, SSH-only management, DHCP, syslog and config backups, and inter-VLAN routing.
The file in the repository titled "Catalyst Switch Lab - Small Office Network Build Guide" is the guide Claude generated for me that I used to follow my procedure and completed requirements.
